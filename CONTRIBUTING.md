# Contributing

Thank you for helping improve LaTeX Studio.

## Before opening an issue

- Search existing issues first.
- Include your operating system, Obsidian version, plugin version, and compiler engine.
- For compilation bugs, include a minimal trusted LaTeX example and the relevant error text. Remove private document content and credentials.

## Development workflow

1. Fork and clone the repository.
2. Install dependencies with `npm ci`.
3. Create a focused branch.
4. Run `npm run check` before opening a pull request.
5. Explain the user-visible behavior and verification performed in the pull request.

Do not commit generated PDFs, build logs, credentials, private vault content, or `main.js`. Release assets are generated by GitHub Actions.
